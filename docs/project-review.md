## Design maintenance

The current profile is an SVG portfolio. All visible names, project descriptions, technologies, skills, interests, and contact details are rendered as SVG text. README.md only arranges picture elements and links. The sequence is: the introduction with the four contact tiles attached beneath it, the three activity panels, skills, tools, LLM workflow, interests, five coloured project tabs, and the five project cards, with Taskflow Local first among projects.

The palette mixes two schemes so the page alternates instead of repeating one ivory card. The newer scheme is black (#0E0F12), cobalt (#2347D9, deep #1A38BC, light #8FA6FF) and ivory (#F5F0E7); it covers the introduction (black and ivory stripes), contact tiles (cobalt), contributions (black), commits (cobalt), skills (black) and the LLM workflow (cobalt). The original scheme keeps repositories (amber), tools (purple), interests (forest) and every project tab and card. Each project keeps its own colours: Taskflow Local burgundy (#96394A / #EAD5D4); Taskflow blue (#315A88 / #D7E2ED); Reconciliation amber (#7B5725 / #EADFC6); CrowdShield forest (#2A6252 / #D5E4DC); Sandman purple (#67487F / #E0D8E9). Colour tabs link to repositories; they are navigation images, not JavaScript theme switches.

The introduction (1200 by 540; mobile 600 by 780) sets the name in hatched, grain-filtered cobalt with an ivory halo, a hard black shadow and a passing sheen, over diagonal black and ivory stripes that drift continuously. Behind it a tesseract turns in the XW and YZ planes and is projected to the page; a quarter turn in both planes maps the cube onto itself, so a quarter-turn SMIL loop rotates endlessly without a seam, and its lines use a difference blend so they read ivory on black stripes and black on ivory. A black block holds the tagline and stack, followed by the KIIT tag and a contact cue whose arrow points at the contact tiles. Contact tiles are four separate images on the line below so that each one links to its destination.

The intro, contact tiles, skills, tools, LLM and interests panels are generated by scripts/static_panels.py from the text at the top of that file, using icons in scripts/icons.json; run it after editing and commit the output. The rebuild also shortened most panels: skills 300 to 222, tools 465 to 312, LLM 365 to 310 and interests 345 to 262 on desktop, with larger savings on mobile. Motion is meant to be fun while staying relevant: skill icons float while an outline steps across the tiles, tool icons take turns to bounce and the React atom spins, a packet travels the LLM pipeline and lights each stage, interest cards carry blinking server lights, a jittering scatter plot and an orbit, and contact icons float while their underlines wipe in turn. Every CSS animation stops with prefers-reduced-motion: reduce; the tesseract shows a still frame instead. No JavaScript, foreignObject, external fonts, or image dependencies are used inside the SVGs.

Python, Java, and Spring Boot lead the skills section, with SQL for relational data. The tool panel names FastAPI, Docker, PostgreSQL, React, OpenCV, LangGraph, MCP, Ollama, Codex, and Claude Code. The author's correction about Rust, Go, and Ruby is respected; these languages are not presented as skills. Project architecture descriptions do not imply personal proficiency in every language in a repository.

The LLM panel describes Codex and Claude Code workflows, custom harnesses, local models, structured outputs, validation, scoped tool access, and agent orchestration, supported by the author’s stated experience and the reviewed Taskflow Local and Sandman implementations. Interests cover backend systems, ML evaluation and vision, and agent infrastructure. Contact tiles link to GitHub, LinkedIn, email, and LeetCode. Icons are original vector line drawings and are labelled with tool names.

The diagrams are conceptual illustrations of reviewed project behaviour, not screenshots. No benchmark, medical, proficiency-percentage, or invented employment claims are included. The structure draws on the project descriptions and concise navigation of [Brittany Chiang](https://brittanychiang.com/), [Lee Robinson](https://leerob.com/), and [Arpit Bhayani](https://arpitbhayani.me/), inspected earlier in this session. No website prose or layout code was copied.

The three activity panels follow the contacts: a contribution heatmap with streaks (black, cobalt heat scale), commits by month (cobalt), and the most active repositories beside the latest commit in each (ivory and amber). Repository bars reuse each featured project's accent and display name. They are generated, not hand-drawn: scripts/activity_panels.py reads public data from the GitHub GraphQL API, and .github/workflows/activity.yml runs it daily and force-pushes the six SVGs as one commit to the `activity` branch, which README.md loads by absolute URL. Commit and repository figures cover public repositories only; private repositories are never named. Merge commits are skipped in the latest-commit list. `--fixture` renders them offline from a saved JSON file. Labels, axes, commit details and figures across the generated panels use Profile Mono, a renamed subset of Cascadia Code (SIL OFL 1.1, licence in scripts/fonts/OFL.txt) embedded as a data URI; headlines keep Georgia and body text keeps Segoe UI. In the activity panels heatmap squares ripple in, a small square hops through the active days in date order and ripples each one, commit squares fall into the monthly bars, repository bars grow in and catch a passing gloss, and a dot runs down a git-log rail under a blinking HEAD tag. At rest, every chart is complete and the decorative pieces are transparent.

Edit README.md for destinations, scripts/static_panels.py for the generated panels, and assets/p5-*.svg for the project tabs and cards. Earlier assets remain for history and are not displayed. Browser verification covers image loading, text bounds and overlap, mobile source selection, horizontal overflow, and reduced-motion behaviour.
